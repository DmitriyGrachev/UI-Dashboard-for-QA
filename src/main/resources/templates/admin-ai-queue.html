About rule statistics

Remaining follows saved priority and file availability, including up to 100 expired assignments recoverable on the next claim. Paused queues show zero. Other counts follow the rule that issued each task and cover retained tasks only. Expired assignments stay in Processing until reclaimed, so the columns should not be added together.

Activity records assignments and accepted results since tracking was enabled. A batch may use several rules; the marker shows the latest recorded batch among saved rules. An assignment may still fail during image preparation. A recorded error describes the last failure, not necessarily the task's current state.
