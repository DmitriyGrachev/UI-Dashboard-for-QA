Operator guide

How to use the review desk

Review a screenshot

Compare the screenshot with the recognition result. Choose Matches when the displayed values agree, or Does not match when they do not. The next assignment loads automatically.

Filters and queue

Filters apply automatically and remain active when you visit Statistics. Date inputs and the oldest/newest matching screenshot dates use UTC. Has user hand matches either active or other recognized user cards. The counter includes the screenshot currently assigned to you. Reset the filters or refresh the page when the queue is empty and you want to check for newly arrived files.

Image controls

Use the mouse wheel or +/- to zoom, drag to pan, 0 to reset, and Fullscreen for a closer inspection. Your zoom level remains active for the next screenshot.

Parse status and assignment

SUCCESS means the supported filename was parsed. PARTIAL means some metadata is incomplete and needs extra attention. A screenshot is reserved for one operator for up to 30 minutes; if that assignment expires, the page loads another item.
